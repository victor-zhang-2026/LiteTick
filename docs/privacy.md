# 妥了 LiteTick Privacy / 隐私说明

## 中文

妥了 LiteTick 是一个完全本地运行的 macOS 待办工具：

- 无需注册或登录。
- 无需网络连接，断网时所有功能均可使用。
- 不包含分析、广告、遥测或第三方追踪组件。
- 不会把待办内容上传到 LiteTick、GitHub 或任何第三方服务器。
- 待办数据和一份自动备份保存在当前 macOS 用户的 Application Support 目录中。

正式版数据位于 `~/Library/Application Support/LiteTick/`，偏好设置使用 `io.github.victor-zhang-2026.litetick` 域。

当前本地数据未加密。能够访问此 macOS 用户文件的人可能读取待办内容。请勿使用 LiteTick 保存密码、银行卡号、身份证号码或其他高度敏感信息。

LiteTick 官方版本不计划加入账号或设备同步。官方维护范围为 macOS 和 Windows，二者均坚持本地离线运行。社区可以基于开源代码探索其他平台，但相关端口与服务不自动代表 LiteTick 官方版本。

## English

妥了 LiteTick is a fully local macOS checklist:

- No registration or sign-in is required.
- Every feature works without an internet connection.
- It contains no analytics, advertising, telemetry, or third-party tracking components.
- It does not upload task content to LiteTick, GitHub, or any third-party server.
- Tasks and one automatic backup are stored in the current macOS user's Application Support directory.

Public-app data is stored under `~/Library/Application Support/LiteTick/`, and preferences use the `io.github.victor-zhang-2026.litetick` domain.

Local data is not currently encrypted. Anyone who can access this macOS user's files may be able to read task content. Do not use LiteTick to store passwords, payment-card numbers, government identifiers, or other highly sensitive information.

Official LiteTick clients do not plan to add accounts or device synchronization. The official maintenance scope is macOS and Windows, both local and offline. The community may explore other platforms from the open-source code, but those ports and services do not automatically represent the official LiteTick release.
