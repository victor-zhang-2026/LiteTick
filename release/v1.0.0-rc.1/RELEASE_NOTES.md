# 妥了 LiteTick 1.0.0-rc.1

首个公开发布候选版本，支持 Apple 芯片 Mac 和 macOS 14 或更高版本。

First public release candidate for Apple silicon Macs running macOS 14 or later.

## Included

- Native floating checklist with immediate Hover access.
- Local-only task persistence and one automatic valid backup.
- Simplified Chinese and English interfaces.
- Light and Dark appearances.
- Completion and restore, Completed search, item pinning, inline editing, and drag reordering.

## Distribution note

This candidate is ad-hoc signed and is not yet signed with Apple Developer ID or notarized. macOS may block the first launch. Follow the repository's install guide only after confirming that the archive SHA-256 matches `SHA256SUMS`.

此候选版使用临时本地签名，尚未经过 Apple Developer ID 签名或公证。macOS 可能阻止首次启动。请先核对压缩包 SHA-256 与 `SHA256SUMS` 一致，再按仓库安装指南操作。
