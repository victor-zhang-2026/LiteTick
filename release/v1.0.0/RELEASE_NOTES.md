# 妥了 LiteTick 1.0.0

首个正式版本，支持 Apple 芯片 Mac 和 macOS 14 或更高版本。

—

First stable release for Apple silicon Macs running macOS 14 or later.

## 内容 / Included

- 原生桌面悬浮清单，可通过鼠标悬停立即打开。
- 任务仅保存在本机，并自动保留一份有效备份。
- 支持简体中文与英文界面。
- 支持浅色和深色外观。
- 支持完成与恢复、已完成搜索、单项置顶、直接编辑和拖动排序。

—

- Native floating checklist with immediate Hover access.
- Local-only task persistence and one automatic valid backup.
- Simplified Chinese and English interfaces.
- Light and Dark appearances.
- Completion and restore, Completed search, item pinning, inline editing, and drag reordering.

## 安装 / Install

- 在 Assets 中下载 `LiteTick-1.0.0-macOS-arm64.zip`；不要下载 `Source code`。
- 解压后，将 `LiteTick.app` 拖入“应用程序”。

—

- Download `LiteTick-1.0.0-macOS-arm64.zip` under Assets; do not download `Source code`.
- Unzip it and drag `LiteTick.app` into Applications.

## 发布说明 / Distribution note

- 此版本采用临时本地签名，尚未经过 Apple Developer ID 签名或公证。macOS 可能阻止首次启动。请先核对压缩包 SHA-256 与 `SHA256SUMS` 一致，再按仓库安装指南操作。

—

- This release is ad-hoc signed and is not yet signed with Apple Developer ID or notarized. macOS may block the first launch. Follow the repository's install guide only after confirming that the archive SHA-256 matches `SHA256SUMS`.
